# Anki 导入说明 —— Java 面试题库

本目录下的 `java-mianshi-anki.txt` 是由 `node tools/export-anki.js` 生成的 Anki 导入文件，共 **548 张卡牌**，覆盖 18 个分类（Java 基础 / 并发 / JVM / Spring / MySQL / Redis / MQ（Kafka）/ Netty / 微服务 / Linux / 算法 / 设计模式 / 游戏服务器 / 场景题 / 简历深挖 / 记忆方法 / 学习方法 / AI 应用）。

## 卡牌设计

| 列 | 内容 |
|---|---|
| 第 1 列（正面） | 分类名 + 难度（基础/进阶/深挖）+ 题干 + 🎯 考点 |
| 第 2 列（背面） | 💡 回答思路 + 📖 参考答案 + 🔁 追问与解答（Q/A 列表）+ 🧠 记忆钩子 |
| 第 3 列 | 标签：分类 id + 难度标签 + 原题目标签（空格分隔） |

正面只给题目和考点，逼自己先主动回忆；背面才放完整答案，适合间隔重复。

## 一、电脑端 Anki 导入步骤

1. **重新生成文件（如题库有更新）**
   ```bash
   node tools/export-anki.js
   ```

2. **打开 Anki** → 菜单栏 **文件（File）→ 导入（Import）**，选择 `anki/java-mianshi-anki.txt`。

3. 在导入对话框中确认以下设置（文件头注释已声明，Anki 通常会自动读取）：
   - **牌型（Note type）**：`Basic`（基础）
   - **牌组（Deck）**：选择 `Java面试题库`（文件头已指定，也可自行新建/选择）
   - **字段分隔符（Field separator）**：`Tab`（制表符）
   - **字段映射**：
     - 字段 1 → **正面（Front）**
     - 字段 2 → **背面（Back）**
     - 字段 3 → **标签（Tags）**（映射框中选择"Tags"，对应文件头 `#tags column:3`）
   - 勾选 **允许在字段中使用 HTML**（Allow HTML in fields）——对应文件头 `#html:true`，不勾选会显示原始 `<br>` 标签。

4. 点击 **导入（Import）**。完成后应提示成功导入 548 条笔记。

5. **按分类/难度筛牌**：在浏览（Browse）界面用标签过滤，例如：
   - `tag:jvm` —— 只看 JVM
   - `tag:难度-深挖` —— 只看深挖题
   - `tag:redis tag:难度-基础` —— Redis 基础题

> 💡 重复导入：题库更新后重新运行脚本再导入，Anki 会按"第一字段"去重；若修改过卡片内容，注意导入对话框中的更新策略选项。

## 二、手机端使用

### AnkiDroid（Android，免费）
1. 电脑端导入完成后，注册/登录 [AnkiWeb](https://ankiweb.net/) 账号。
2. 电脑端 Anki 点 **同步（Sync）** 上传到 AnkiWeb。
3. 手机装 AnkiDroid → 登录同一 AnkiWeb 账号 → 点同步图标即可拉到全部卡牌。

### AnkiMobile（iOS，付费）
流程相同：电脑端同步到 AnkiWeb → AnkiMobile 登录同步。

> 也可以直接把 `.txt` 文件传到手机导入，但**强烈推荐走 AnkiWeb 同步**：学习进度（哪张卡该复习了）会在所有设备间保持一致。

## 三、间隔重复的正确用法

Anki 的价值在于**按遗忘曲线安排复习**，关键在于诚实评分：

- **Again（重来 / 模糊 / 不会）**：答不上来、卡壳、或只能说出大概——**果断点 Again**。这张卡会很快（默认 1~10 分钟内）再次出现，直到你能流畅答出。不会就点 Again 不是失败，是把时间精准花在没掌握的内容上。
- **Hard（困难）**：答对了但很吃力、耗时长。
- **Good（良好）**：正常答出。绝大多数卡应落在这里。
- **Easy（简单）**：脱口而出、毫无压力。慎点，点了会大幅拉长间隔。

**针对本题库的建议**：

1. **模拟口试，出声作答**：看正面后，先按背面的"💡 回答思路"要求自己——能不能不提示就给出结论 → 展开 → 挖坑规避？能，才配点 Good。
2. **追问是重点**：背面的 🔁 追问是面试官真正拉开差距的地方。答主答案但追问全卡壳的，点 Again 或 Hard。
3. **记忆钩子只是药引**：🧠 记忆钩子帮你记住结构，但真正要练的是展开成 2~3 分钟的口头表达。
4. **每天固定节奏**：建议每天新卡 15~20 张 + 复习到期卡，约一个月覆盖全部 548 题；面试前一周把 `tag:难度-深挖` 和 `tag:resume-deepdive` 再过一遍。
5. **配合 30 天计划**：`memory` 分类里有完整的复习计划题卡，建议先把该分类的新卡放出来。

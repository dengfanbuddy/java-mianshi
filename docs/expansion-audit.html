二、7 个「数据已在、功能未做」的扩展点

🏷️
E1. 标签系统：点击筛选 + 标签聚合视图
全库 554 题都有 tags（如「分布式锁」「GC」「线程池」），但当前只在卡片底部灰色展示，不可点。做成：点标签 → 跨分类筛出所有同标签题；另加「标签云视图」看薄弱面（哪些标签错题多）。
小 P0 · 数据 100% 在，纯 UI 交互 · 依托 matchKw/renderGlobal

E2. 追问链练习模式（防「背答案」）
每题的 followups（面试官深挖追问）现只展开显示。做成「追问模式」：题目卡片只显示追问 Q，自答后点开 A —— 专门练「被追问时的临场反应」，比背大段答案高效。
小 P0 · 复用自测模式交互 · 依托 followups 100% 覆盖
🧠
E3. 记忆钩子速览模式（考前 15 分钟）
每题的 memory（口诀/类比）是压缩的记忆点。做「钩子速览」：全分类/单分类一屏刷钩子（题干 → 钩子），考前快速过一遍全部记忆锚点，替代翻 print.html 长文档。
小 P0 · 纯展示层新视图 · 依托 memory 100% 覆盖
🔀
E4. 跨分类混合自测（当前只能单分类）
自测模式 startQuiz() 只取 window.QB[curCat] 单分类。扩展：全局范围抽题（可勾选「混合分类」）、错题本抽题重测、到期复习抽题——按 scopeAll 逻辑天然支持，改几行。
小 P1 · 复用 shuffle/grade 逻辑 · 依托 scopeAll 已有开关
📅
E5. 复习历史与学习热力图（把时间戳变数据）
localStorage 已存 qb_done_ts（掌握时间）、qb_review（复习轮次）、qb_wrong（错题时间）——但统计看板只用了「当前快照」，没有任何历史曲线。做成：近 30 天学习热力图 + 每日刷题/掌握/复习趋势线 + 复习轮次分布。
中 P1 · 纯前端读 localStorage · 依托现有 3 个时间戳存储
🔗
E6. 教程「已学完」自动同步题目掌握
教程节点 covers 声明关联题目，但「标记已学完」只记录教程状态。扩展：标记已学完时，其 covers 的题若从未掌握 → 提示「同步标记掌握？」；随堂小测答对 → 该题直接计掌握。把「学完=会做」的隐含关系显式化。
小 P1 · 依托 covers 100% 覆盖 + setTutDone
🗂️
E7. 错题本按分类/难度聚合
错题本现在是按时间平铺的列表。扩展：按分类分组展示 + 每分类错题数角标（看哪个分类最薄弱）+ 「全分类错题抽测」。错题数据里有 cat/level 字段，现成可用。

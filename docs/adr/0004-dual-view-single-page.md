# ADR-0004：同页双视图架构（教程不拆独立页面）

- 日期：2026-08-07
- 状态：已接受

## 背景

教程 UI 如何呈现。候选：同一 index.html 内双视图切换 / 弹窗浮层 / 独立 tutorial.html 页面。

## 决策

在现有单页应用内新增「教程视图」，与「刷题视图」平行切换。教程视图内部再分两级：**图谱视图**（SVG DAG 总览）→ **阅读视图**（左章节目录 + 右正文）。两视图主题/进度状态各自独立保存。所有「去补课」入口（题目卡片、自测不会、错题本、间隔重复答错）跳转到阅读视图并携带返回点。

## 理由

- 闭环联动（补课 → 返回重测）在同一页面内实现，无跨页状态同步问题。
- 保持现有单文件架构与 file:// 可用性。
- 弹窗浮层长文阅读体验差，移动端尤甚。否决。
- 独立页面需跨页同步进度与联动参数，复杂度不成比例。否决。

## 后果

- index.html 体积进一步增长，需注意代码组织（图谱渲染、教程渲染模块化）。
- 教程视图需自己的滚动/进度状态管理。

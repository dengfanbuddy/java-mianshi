# ADR-0003：题目-教程关联采用教程侧 covers 显式映射

- 日期：2026-08-07
- 状态：已接受

## 背景

「错题/不会题 → 补课直达」闭环需要题目与教程节点之间的映射。候选：教程节点显式声明题目 ID / 运行时按 tags 自动匹配 / 仅分类级泛链接。

## 决策

教程节点声明 `covers` 字段（题目 ID 数组），生成教程时对照题库手工映射；题库侧零改动。每个分类额外声明兜底 `fallback`（该分类下无 covers 匹配时使用的默认节点，用于兜底关联不到的题）。

## 理由

- 显式 ID 映射精确可靠，杜绝"不会题→错教程"。
- 生成教程时同步完成映射，无运行时匹配成本，无额外维护面。
- 题库已冻结，侧零改动零回归风险。

## 权衡

- tags 自动匹配：零维护但同名 tag 可对应多个节点，映射不可靠。否决。
- 分类级泛链接：实现最简但直达做不到，闭环价值大打折扣。否决。
- 代价：新增题目后需补映射（可纳入题目质检流程）。

## 后果

- 教程数据结构固定含 `covers` 与兜底映射，数据质检脚本需校验 ID 存在性。

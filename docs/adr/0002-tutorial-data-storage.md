# ADR-0002：教程数据独立存储（data/tutorials + window.TB + 内联 SVG）

- 日期：2026-08-07
- 状态：已接受

## 背景

教程数据需要与题库数据并存。候选：并入现有 `data/*.js` / 独立目录 `data/tutorials/` / 独立 md+svg 文件运行时 fetch。

## 决策

新增 `data/tutorials/` 目录，每分类一个 js 文件，全局格式 `window.TB['分类id'] = {...}`，与题库 `window.QB` 平行。SVG 图解以**字符串内联**进教程数据。

## 理由

- 题库已稳定（554 题），教程是持续增量资产，分开存放互不干扰、可独立制作/质检/更新。
- 每分类独立文件便于分批生成、按需加载。
- file:// 双击 index.html 可直接使用（不依赖服务器），保持单文件应用架构。
- SVG 内联避免文件系统依赖，离线可用、无路径管理成本。

## 权衡

- 并入题库文件：文件体积翻几倍（70~125KB → 300KB+），且改教程易误碰题库。否决。
- md+svg 独立文件：排版自由但需本地服务器，破坏现有"双击即用"。否决。

## 后果

- 制作流程：每分类一个生成单元，产物为单个 js 文件。
- SVG 内联使数据文件较大（预期 200~400KB/分类），本地加载无压力。

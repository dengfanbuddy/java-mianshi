二、核心机制缺口（「学了记不住」的根源）

🔴 缺口 1：复习无「答对/答错」反馈采集

「今日到期复习」只有 ✓ 已复习 一个按钮，不区分对错。就算复习时完全想不起来，系统也照样把该题推进到下一周期。这是记不住的最直接成因——记忆系统对「你还不会」的事实无感知。

🔴 缺口 2：自测评分不回流 SRS 调度

自测模式的 1/2/3（会/模糊/不会）只影响错题本，不会调整复习间隔。「模糊」的题 3 天后照样按原节奏复习，没有「答得越差、排得越密」的机制。

🟠 缺口 3：固定节奏无记忆曲线

1/3/7/15 是拍脑袋的固定间隔。FSRS-4.5 这类算法根据每次复习的评分动态调整间隔（答得好的间隔指数级拉长、答得差的缩短），长期留存率显著更高——Anki 2023 年起已全量内置。

🟠 缺口 4：教程学习与复习割裂

教程「已学完」和题库「已掌握」是两套独立状态。学完一篇教程没有触发对应的题目复习；补课回来也缺少「学完 → 重测 → 确认掌握」的验收闭环（现有补课只做了直达，未做回测）。

🟠 缺口 5：掌握度只有二元态

题目只有「已掌握/未掌握」，没有中间档。统计看板显示的是 0/100% 的平面视图，无法回答「哪些题是弱掌握、该优先复习」。

三、扩展机会清单（按优先级排序）

🅰 学习机制增强（主轴 · 直接解决「记不住」）

机会要点收益工作量优先级
A1. 复习反馈闭环 到期复习页加「答对 ✓ / 答错 ✗」判定。答错 → 间隔重置回 1 天 + 自动进错题本 + 一键补课；答对 → 正常推进 记忆系统第一次感知「你不会」，是当前最高杠杆改动 小 P0
A2. 自测评分回流 SRS 自测「模糊/不会」→ 该题间隔重置 + 提前到期；「会」→ 正常推进。与 A1 共用一套评分 → 调度逻辑 所有学习行为统一驱动复习节奏，不再各管各 小 P0
A3. FSRS 动态间隔 复习评分升级为四档（重来/困难/良好/轻松），间隔按 FSRS-4.5 公式动态计算（纯前端 ~200 行，无依赖） 间隔指数级适配记忆强度，长期留存率明显提升 中 P1
A4. 教程→题目复习联动 教程「已学完」→ 其 covers 的题目 1 天后自动进入到期复习；补课回测：学完 → 重做原题 → 才确认掌握 打通学测闭环，教程学习真正作用于记忆 中 P1
A5. 掌握度分级 题目状态 0-4 档（未学/弱/中/强/稳固），由 SRS 评分历史推导；看板按掌握档着色，筛「弱掌握优先复习」 从平面 0/100 升级为可操作的复习优先级 中 P1
A6. 学习计划生成器 输入目标日期 + 每日可用时长 → 按难度/分类权重自动排每日任务（N 题 + M 篇教程 + 到期复习），勾选即完成 把「554 题 + 256 篇」的庞大内容折叠成每天的确定清单 大 P2

四、推荐路线图

1
止血（1 天）：A1 复习反馈 + A2 评分回流

最小改动让记忆系统感知「不会」：复习页双按钮、答错重置间隔 + 错题本 + 补课入口；自测评分统一走同一调度。直接命中「学了记不住」。

2
闭环（1-2 天）：A4 教程联动 + B1 每日推送

教程学完触发题目复习、补课带回测验收；每天 5 题固定锚点。学→测→复习→补课全链路打通。

3
进化（可选）：A3 FSRS + A5 掌握度 + B2 模拟面试

FSRS 四档评分接管间隔计算；掌握度分档驱动看板与复习优先级；模拟面试场次做最终冲刺演练。此阶段各功能独立、可挑选。

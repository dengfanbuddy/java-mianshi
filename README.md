# Java 游戏服务器面试题库 · 邓凡专属复习版

针对 `邓凡-Java(1).pdf` 简历定制的面试复习题库，共 **18 个分类、548 道题**（已经过资深面试官视角的全量审题补漏），每题含：参考答案、举一反三追问（面试官深挖路径）、记忆钩子（口诀/类比）。

## 快速开始

```bash
npm run dev        # 启动本地预览，默认 http://localhost:7100/
npm run dev -- --port 8080   # 指定端口
```

也可以直接用浏览器打开 `index.html`。

## 功能

- 左侧：18 个分类导航 + 每类掌握进度条 + 总进度
- 右侧：题目卡片，点击展开 考点 / 回答思路 / 参考答案 / 追问解答 / 记忆钩子
- 每题五件套：🎯 考点（面试官真正考什么）→ 🧭 回答思路（怎么答、避什么坑）→ 📖 参考答案 → 🔥 举一反三追问（每条均配解答）→ 🧠 记忆钩子
- 难度筛选：基础必会 169 题（约32%）→ 进阶高频 257 题（约48%）→ 深挖架构 104 题（约20%），循序渐进
- 全文搜索：题干 / 答案 / 标签 / 追问，支持勾选「全部范围」跨 17 个分类全局检索，**搜索关键词自动高亮**
- 「标记掌握」按钮：进度存在浏览器 localStorage，关掉页面不丢失
- 💾 **进度备份/恢复**：一键导出 JSON 备份文件，换设备/清缓存前先备份，随时恢复
- 📊 **统计看板**：总体掌握率（环形图）+ 难度分布（饼图）+ 各分类进度条 + 错题/到期复习数据
- 🌙 **深色模式**：一键切换浅色/深色主题，自动记忆偏好，夜间复习不刺眼
- 🎯 自测模式：当前筛选范围内随机抽题，先自答再对答案，自评「会/模糊/不会」，模糊与不会自动进错题本
- 📕 错题本：集中攻坚薄弱题，掌握后自动移出
- 📅 间隔重复：按 1/3/7/15 天节奏计算「今日到期复习」，侧栏一键进入
- ⌨️ 快捷键：自测模式 空格=显示答案/下一题，1/2/3=会/模糊/不会；普通模式 `/`=聚焦搜索
- 📱 移动端：窄屏侧栏可折叠（汉堡按钮），手机上也能刷题
- 🖨️ 打印版 `print.html`：候场速览（题干+考点+记忆钩子）/ 完整手册两种视图，Ctrl+P 直接打印或另存 PDF
- 📇 Anki 导出：`node tools/export-anki.js` 生成 `anki/java-mianshi-anki.txt`，导入 Anki 手机刷题（见 `anki/README-导入说明.md`）
- 📘 **教程知识库（新）**：16 个技术分类带「📘 教程」入口 → 四层知识图谱（入门→核心→进阶→实战，箭头=推荐学习顺序，所有章节随时可学）→ 八段结构章节（定位/前置/讲解/代码/SVG图解/坑/关联题/小结）→ 每篇 1~3 张内联 SVG 图解（跟随深浅色主题）
- 🔗 **补课闭环**：题目卡片 / 错题本 / 自测「模糊·不会」/ 间隔重复答错 → 一键「📘 补课」直达对应教程章节，学完「标记已学完」回来重测
- 🧪 **随堂小测 + 📝 笔记**：每篇末尾 3 题随堂测（答错自动进错题本）+ 个人笔记（本机保存，复习优先回看）
- 🔍 **教程全文搜索**：勾选「📘 搜教程」后搜索框跨全部教程正文/代码/图解标注检索
- 🖨️ **教程打印**：图谱页打印全分类、阅读页打印本篇，Ctrl+P 导出 PDF 离线看

## 记忆方法速览（详见题库「记忆方法」分类）

1. **主动回忆**：展开答案前先口头自答，再对照 —— 比重复阅读效率高数倍
2. **费曼学习法**：把每个知识点讲给"不懂技术的人"听，讲不顺的就是没懂
3. **间隔重复**：按 1 天 / 3 天 / 7 天 / 15 天节奏回看标记过的题（可导入 Anki）
4. **场景绑定**：把知识点绑到你自己的项目故事上（如"Redis 分布式锁 → 活动资格防重那次设计"）
5. **演进链串联**：单点 → 主从 → 哨兵 → 集群，记住"每次演进解决了什么问题"即记住全部
6. **口诀/类比**：每题自带一条记忆钩子
7. **模拟面试**：录音自答，回听找"嗯/然后/就是"等口头问题
8. **结论先行**：答题用总-分-总，先给一句话结论
